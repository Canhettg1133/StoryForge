Chưa Kết Nối Extension

Để gửi tin nhắn hàng loạt tự động trực tiếp qua Zalo Web, bạn cần cài đặt Chrome Extension hỗ trợ.

Cách cài đặt đơn giản:
  1. Tải thư mục tools/lead-connector-extension
  2. Vào chrome://extensions trên trình duyệt
  3. Bật Chế độ nhà phát triển
  4. Chọn Load unpacked rồi chọn thư mục extension
