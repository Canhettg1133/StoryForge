Quota Gemini do Google tính theo project. Nhiều key cùng project có thể dùng chung quota.

🌐 Gemini Proxy AG Tắt

🔄 Gemini Proxy AG: Provider preset mặc định cho AG, dùng model có sẵn và key pool riêng.

⚠️ Lưu ý: Số luồng song song theo cài đặt chung; ít key chạy nhiều luồng dễ gặp 429/403.

Sử dụng Gemini Proxy AG
Có thể nhập root URL hoặc full endpoint kết thúc bằng /chat/completions.
Key dùng để xoay tua. Số luồng song song không bị khóa theo số key.

💡 Mẹo dùng Gemini Proxy AG:

  • 1 key vẫn có thể chạy nhiều luồng, nhưng dễ bị rate limit nếu đặt quá cao.
  • RPM mỗi API key: đặt theo quota thật của proxy để hệ thống tự chờ khi hết slot.
  • Chunk size: 2000-3000 ký tự
  • Khi bật Gemini Proxy AG, hệ thống sẽ bỏ qua Gemini Direct

🧩 Custom Proxy Tắt

Custom Proxy: Dùng endpoint OpenAI-compatible riêng như one-api, NewAPI, OpenRouter hoặc proxy nội bộ.

Tách riêng: Key/model ở đây dùng pool openai_proxy, không trộn với Gemini Proxy AG.

Sử dụng Custom Proxy
